تراز | نسخه ایرانیزه با تقویم شمسی و تم سورمه‌ای

چرا قبلاً صفحه سفید بود؟
نسخه وب از JavaScript Module استفاده می‌کند و نباید با دوبار کلیک روی index.html (آدرس file://) باز شود. در این بسته، فایل app.js هم کنار index.html قرار دارد و اجرای محلی با وب‌سرور ساده فراهم شده است.

اجرای محلی در ویندوز:
1) همه فایل‌های ZIP را در یک پوشه استخراج کنید.
2) روی RUN-LOCAL.bat دوبار کلیک کنید.
3) مرورگر باید آدرس http://127.0.0.1:8000 را باز کند.
4) پنجره مشکی را تا زمانی که از برنامه استفاده می‌کنید نبندید.
5) اگر Python نصب نیست، Python 3 را نصب کنید و دوباره RUN-LOCAL.bat را اجرا کنید.

تنظیمات محلی ایران:
- زبان رابط فارسی و راست‌چین است.
- تاریخ‌ها بر اساس تقویم هجری شمسی و منطقه زمانی Asia/Tehran نمایش داده می‌شوند.
- مبلغ‌ها به تومان هستند و می‌توانید رقم‌ها را فارسی یا لاتین وارد کنید.
- ماه در دیتابیس به شکل کلید شمسی 1405-08 نگهداری می‌شود؛ تاریخ‌های واقعی برای سازگاری با PostgreSQL به‌صورت ISO میلادی در ستون DATE ذخیره می‌شوند و در برنامه شمسی نمایش داده می‌شوند.
- هنگام ثبت اطلاعات، تاریخ باید در همان ماه شمسی انتخاب‌شده باشد.

اتصال Supabase:
config.js را باز کنید و مقادیر پروژه خود را قرار دهید:
window.APP_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY"
};
فقط کلید عمومی anon/publishable مجاز است؛ هرگز service_role یا secret key را در مرورگر قرار ندهید.

سپس فایل supabase-schema.sql را در SQL Editor پروژه Supabase اجرا کنید.
در Supabase > Authentication > URL Configuration آدرس محلی و بعداً آدرس GitHub Pages را به Redirect URLs اضافه کنید.

انتشار GitHub Pages:
فایل‌های index.html, style.css, app.js, config.js و .nojekyll را در ریشه repository قرار دهید؛ همچنین supabase-schema.sql را برای نگهداری کنار بگذارید. در Settings > Pages شاخه main و پوشه /(root) را انتخاب کنید.

نکات:
- اطلاعات مالی در Supabase ذخیره می‌شوند؛ پاک‌کردن کش مرورگر داده‌های ابری را حذف نمی‌کند.
- با تعویض دستگاه، باید یک‌بار با همان ایمیل و رمز وارد شوید.
- برای اجرا نیاز به اینترنت جهت دریافت Supabase JS و Chart.js و فونت است.

فونت رابط کاربری:
- خانواده فونت Pinar در تمام بخش‌های برنامه استفاده می‌شود و فایل‌ها به‌صورت محلی داخل پوشه fonts قرار دارند؛ بنابراین نیازی به دریافت فونت از Google Fonts نیست.
- Regular (400): متن‌های عادی
- Medium (500): متن‌های کمکی و اجزای رابط
- SemiBold (600): دکمه‌ها، برچسب‌ها و عنوان‌های بخش‌ها
- Black (900): تیترهای اصلی و اعداد برجسته
- برای انتشار روی GitHub Pages، پوشه fonts را همراه سایر فایل‌ها در ریشه repository آپلود کنید.
