تراز | اتصال پیامک بلو بانک به آیفون
به‌روزرسانی نهایی برای پروژه Taraz Pinar V5

این بسته، نسخه کامل قبلی را از نو نمی‌سازد. آن را روی پوشه استخراج‌شده taraz-saman-v5 اعمال کن تا طراحی، فونت Pinar، تقویم شمسی، دیتابیس و سوابق قبلی حفظ شوند.

مشخصات فرستنده تأییدشده از نمونه کاربر:
+98 999 998 7641
قالب بین‌المللی بدون فاصله: +989999987641
قالب داخلی نرمال‌شده: 09999987641

پیامک‌های پشتیبانی‌شده در نسخه اولیه:
- برداشت پول: هزینه / برداشت
- واریز پول: درآمد / واریزی
- خرید بسته اینترنت، مصرف اینترنت و پیام «آنلاین شدی»: هزینه اینترنت
- پیامک رمز پویا و کدهای امنیتی نادیده گرفته می‌شوند.

واحد مبلغ:
در نمونه‌هایی که کاربر فرستاده، مبلغ تراکنش به ریال است. برنامه مبلغ ریالی را تقسیم بر ۱۰ می‌کند و به تومان در تراز ذخیره می‌کند. اگر متن صریحاً «تومان» داشته باشد، مقدار را دوباره تقسیم نمی‌کند.

مرحله ۱: اعمال به‌روزرسانی روی پروژه فعلی
۱. ZIP این بسته را استخراج کن.
۲. فایل APPLY-BLU-UPDATE.bat را اجرا کن.
۳. مسیر پوشه استخراج‌شده پروژه قبلی taraz-saman-v5 را وارد کن. مسیر باید همان پوشه‌ای باشد که index.html و app.js داخلش هستند.
۴. اسکریپت، تابع قدیمی سامان را با تابع blu-sms-ingest جایگزین می‌کند، نام بانک را در رابط کاربری تغییر می‌دهد و راهنمای بلو را اضافه می‌کند. فایل‌های اصلی، فونت‌ها و اطلاعات دیتابیس را پاک یا بازنویسی نمی‌کند.

مرحله ۲: دیتابیس
فایل bank-sms-schema.sql همراه همین بسته است. آن را در Supabase > SQL Editor اجرا کن. این اسکریپت با جدول‌های قبلی سازگار است و داده‌های درآمد و هزینه را حذف نمی‌کند. اگر قبلاً migration پیامک V5 را اجرا کرده‌ای، اجرای دوباره این فایل برای به‌روزرسانی مقدار پیش‌فرض نام بانک امن است.

مرحله ۳: انتشار تابع جدید
روش پیشنهادی با Supabase CLI:
۱. Supabase CLI و حساب پروژه را راه‌اندازی کن.
۲. از ریشه پوشه پروژه این دستورات را اجرا کن:
   supabase login
   supabase link --project-ref yqficypwipahefwcotct
   supabase functions deploy blu-sms-ingest --no-verify-jwt
۳. بعد از انتشار، تابع در این نشانی در دسترس است:
   https://yqficypwipahefwcotct.supabase.co/functions/v1/blu-sms-ingest

گزینه --no-verify-jwt لازم است چون تابع با کلید اختصاصی دستگاه احراز هویت می‌کند. کلید را با هش SHA-256 در جدول bank_sms_devices بررسی می‌کند. تابع از کلید محرمانه Supabase فقط در سمت سرور استفاده می‌کند.
هرگز service_role یا secret key را داخل سایت یا Shortcut قرار نده.

اگر از Dashboard منتشر می‌کنی:
۱. Edge Functions > Deploy a new function > Via Editor را باز کن.
۲. نام تابع را دقیقاً blu-sms-ingest بگذار و محتوای supabase/functions/blu-sms-ingest/index.ts را قرار بده.
۳. تابع را Deploy کن.
۴. در تنظیمات تابع، JWT Verification را خاموش کن تا درخواست Shortcuts به تابع برسد. تابع خودش کلید دستگاه را بررسی می‌کند.

مرحله ۴: ساخت کلید اختصاصی آیفون
۱. برنامه تراز را با پوشه به‌روزشده باز کن.
۲. وارد حساب قبلی تراز شو.
۳. تنظیمات را باز کن.
۴. در بخش اتصال پیامک بلو، روی «ساخت کلید اتصال آیفون» بزن.
۵. کلید را کپی کن. این کلید فقط یک بار نمایش داده می‌شود. در صورت گم شدن، از داخل تراز کلید تازه بساز؛ کلید قبلی لغو می‌شود.

مرحله ۵: اتوماسیون آیفون
۱. Shortcuts را باز کن و وارد Automation شو.
۲. New Automation > Message را انتخاب کن.
۳. در Sender، فرستنده واقعی پیامک را انتخاب کن. شماره آن باید +98 999 998 7641 باشد. اگر در فهرست به شکل 09999987641 دیده می‌شود، همان را انتخاب کن.
۴. قسمت Message Contains را خالی بگذار تا پیام‌های مختلف برداشت، واریز و اینترنت دریافت شوند. تابع سمت سرور پیام‌های غیرتراکنشی و رمز پویا را نادیده می‌گیرد.
۵. Run Immediately را انتخاب کن؛ در نسخه‌هایی که این گزینه را ندارند، Confirm Before Run را خاموش کن. اگر گزینه Allow Running When Locked وجود دارد و می‌خواهی اتوماسیون در حالت قفل اجرا شود، آن را فعال کن.
۶. اکشن‌های زیر را اضافه کن:
   الف) Get Text from Input؛ ورودی همان Shortcut Input پیام دریافتی باشد.
   ب) Current Date.
   ج) Format Date؛ قالب ISO 8601 را انتخاب کن.
   د) Get Contents of URL؛ تنظیمات زیر را وارد کن.

Get Contents of URL:
URL:
https://yqficypwipahefwcotct.supabase.co/functions/v1/blu-sms-ingest
Method: POST
Headers:
Content-Type = application/json
apikey = کلید عمومی Publishable پروژه Supabase که با sb_publishable_ شروع می‌شود
x-taraz-device-token = کلید خصوصی دستگاه که از تنظیمات تراز کپی کردی

Request Body: JSON
message = خروجی Get Text from Input
received_at = خروجی Format Date
sender = +989999987641

۷. پس از Get Contents of URL، اکشن Get Dictionary Value را اضافه کن. Key برابر notification و ورودی آن نتیجه Get Contents of URL باشد.
۸. اکشن Show Notification را اضافه کن و خروجی notification را به آن بده.
۹. اتوماسیون را ذخیره کن.

مرحله ۶: انتشار رابط کاربری
پس از اجرای اسکریپت به‌روزرسانی، پوشه پروژه را روی GitHub Pages دوباره بارگذاری کن. اگر با پوشه محلی اجرا می‌کنی، سرور RUN-LOCAL.bat را ببند و دوباره اجرا کن. در مرورگر Refresh سخت (Ctrl+F5) انجام بده.

مرحله ۷: آزمایش
۱. یک پیامک واقعی برداشت یا واریز از بلو دریافت کن.
۲. باید اعلان Shortcuts با نتیجه پردازش ظاهر شود.
۳. تراز را باز کن؛ تراکنش در صف «تراکنش‌های بانکی در انتظار تأیید» نمایش داده می‌شود.
۴. عنوان، دسته‌بندی و توضیح را بررسی کن.
۵. «تأیید و ثبت» را بزن. واریز در درآمدها و برداشت در هزینه‌ها ثبت می‌شود.
۶. برای جلوگیری از ثبت تکراری، شناسه اثرانگشت پیامک در دیتابیس یکتا است.

نکات امنیتی و محدودیت‌ها
- این اتصال به پیامک‌های دریافتی وابسته به Automation آیفون است؛ وب‌اپ مستقیماً صندوق پیامک را نمی‌خواند.
- نوتیفیکیشن اولیه توسط Shortcuts نشان داده می‌شود. برای نوشتن و تأیید مستقیم داخل خود نوتیفیکیشن، اپلیکیشن Native iOS لازم است.
- متن کامل پیامک در دیتابیس ذخیره نمی‌شود. فقط مبلغ، نوع تراکنش، زمان، برچسب کوتاه مبدأ/مقصد در صورت تشخیص، و هش جلوگیری از تکرار ذخیره می‌شوند.
- رمز پویا، کد ورود و متن‌هایی که مبلغ تراکنش روشن ندارند وارد حساب نمی‌شوند.
- مبلغ‌های بدون واحد به‌صورت پیش‌فرض ریال فرض می‌شوند، چون نمونه پیامک‌های ارائه‌شده ریالی بودند. اگر متن صریحاً تومان داشته باشد، همان تومان محاسبه می‌شود.
- نام پذیرنده یا مبدأ فقط وقتی در الگوی پیامک قابل تشخیص باشد ثبت می‌شود؛ هیچ نامی حدس زده نمی‌شود.
- اتوماسیون را ابتدا با یک پیامک واقعی آزمایش کن و مجموع ریال/تومان را با پیامک بانک تطبیق بده.
